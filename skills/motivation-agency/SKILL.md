# Support motivation without stealing agency

## Mental model

Gamification and habit-forming interfaces use feedback, progress, novelty, and low-friction interaction. Those mechanisms need to be evaluated against the user’s goal, not assumed to be desirable because they increase engagement.

## When this skill applies

Use when adding streaks, rewards, achievements, infinite content, or recurring prompts.

## Reasoning

Name the goal the person chose and the behavior that supports it. Make feedback informative and proportionate. A completion signal can acknowledge useful progress without turning every interaction into a reward chase.

Give people clear control over repetition and reminders. Preserve visible stopping points and ordinary navigation. Distinguish beneficial return usage from compulsive continuation when evaluating the design.

## Worked example — original implementation adaptation

A learning dashboard

Before: a lost streak triggers alarming prompts and more content starts automatically after each lesson.

After: progress reflects completed learning goals; reminders are optional, breaks are ordinary, and completing a lesson offers an explicit next step or a stopping point.

## Failure modes

- Using session length as the only success measure.

- Punishing absence or hiding the option to stop.

- Rewards that encourage superficial activity instead of the actual goal.

## Evidence that would support the decision

Observe whether users can finish, stop, resume, and disable recurring prompts. Evaluate the chosen outcome separately from clicks or time spent.
