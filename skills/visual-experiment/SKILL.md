# Bound the visual experiment

## Mental model

Visual novelty can create character and draw attention. Its usefulness depends on context, hierarchy, readability, and how well the interaction still works when the effect is absent.

## When this skill applies

Use for a distinctive marketing direction or a proposed effect whose cost and purpose are unclear.

## Reasoning

State what the experiment should communicate: material, personality, product structure, or a focal idea. Keep it separate from essential content so the effect can be reduced or removed without losing meaning.

Prototype a bounded version before applying it widely. Compare the same composition with and without the effect. Consider motion preferences, media load, legibility, and small-screen fallback alongside the visual result.

## Worked example — original implementation adaptation

A 3D product hero

Before: a large interactive scene delays the page and contains the only product explanation.

After: live text and a usable action load independently; an optional scene adds a relevant product cue. A static fallback preserves the composition, and motion can be reduced.

## Failure modes

- Treating every trend as suitable for every product.

- A decorative layer that captures pointer input.

- Novelty mistaken for evidence of usability.

## Evidence that would support the decision

Compare effect-on and effect-off versions, slow media, narrow viewports, and reduced motion. Confirm the message and task still hold.
