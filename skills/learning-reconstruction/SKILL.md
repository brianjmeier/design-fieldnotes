# Learn by reconstructing and explaining

## Mental model

Rebuilding and redesigning can expose the decisions hidden in finished work. A useful exercise connects the observed result to the structure and choices that create it, then tests whether those choices transfer.

## When this skill applies

Use for improving design judgment, building a truthful portfolio exercise, or training an agent on a new interface pattern.

## Reasoning

Choose a bounded real interface and describe its task. Reconstruct its layout and key states with comparable content. Explain where alignment, hierarchy, type, color, and behavior do the work.

Change the content or task and adapt the design. This transfer reveals which decisions were contextual. Label speculative work honestly, avoid fabricated client results, and preserve the source reference.

## Worked example — original implementation adaptation

A portfolio support-queue exercise

Before: a copied dashboard screenshot is presented as a completed client project.

After: the exercise is labeled as a concept study. It explains the task, reconstructed mechanism, adapted content, and tested behavior, with truthful limits and source attribution.

## Failure modes

- Mistaking an attractive imitation for transferable understanding.

- Fake client or user-research claims.

- Practicing only the perfect default state.

## Evidence that would support the decision

Explain the mechanism in your own words, then demonstrate it with different content and a recoverable failure. Keep the evidence and attribution visible.
