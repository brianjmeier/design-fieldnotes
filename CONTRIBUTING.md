# Contributing

Start with [DATA.md](DATA.md) and [METHODOLOGY.md](METHODOLOGY.md). Write a skill as a mechanism that helps a particular decision, with a concrete example and failure modes. Keep behavioral verification separate from the concept.

Support new teaching with a public source and a timestamp within its duration. Record whether evidence is captions, sampled frames or a complete visual review. Do not infer claims from titles alone or silently turn historical recommendations into present-day requirements.

Edit canonical data and source files, run the build and validator, then check the actual website: browse/search, no-match recovery, a skill’s copy/download paths, source attribution, methodology, keyboard destinations and narrow-screen reflow. Preserve usable context when readers return to the collection.

A screenshot proves a visible state, not a completed workflow or accessibility conformance. Describe precisely what changed and how it was verified. Submit source edits and regenerated exports together; keep generated data consistent and preserve attribution.
